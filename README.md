# 📊 Modelo de Imposto de Renda - Excel

## 📌 Sobre o projeto

Este projeto consiste em um modelo desenvolvido no Microsoft Excel para auxiliar a pessoa física na organização de informações utilizadas na preparação da declaração do Imposto de Renda.

A planilha foi criada com o objetivo de centralizar e organizar informações pessoais e financeiras, facilitando o preenchimento e a consulta dos dados.

## 🎯 Finalidade

A finalidade da planilha é facilitar a organização das informações necessárias para a preparação da declaração do Imposto de Renda de Pessoa Física (IRPF).

## 🔎 Objetivo

O objetivo é oferecer uma ferramenta simples e organizada para registrar informações como:

- Dados do titular;
- Informes de rendimentos;
- Informações bancárias;
- Entradas financeiras;
- Dados provenientes de holerites;
- Instituições bancárias.

## 🛠️ Método de criação

O projeto foi desenvolvido no Microsoft Excel, utilizando fórmulas, tabelas de apoio, organização de dados e recursos de validação para facilitar o preenchimento das informações.

A planilha foi estruturada em diferentes abas, separando os dados de acordo com sua finalidade.

## 📂 Estrutura da planilha

### 👤 Titular

Área destinada ao preenchimento dos dados pessoais do titular.

### 🏦 Informes

Área destinada à organização dos informes de rendimentos e informações relacionadas às instituições financeiras.

### 💰 Notas

Área destinada ao registro e organização das entradas financeiras.

### 📋 Tabelas

Área utilizada como base de apoio para informações utilizadas na planilha.

## 🧰 Ferramentas utilizadas

- Microsoft Excel
- Fórmulas e funções do Excel
- Tabelas de apoio
- Validação de dados
- Organização e estruturação de informações
